# Orty tickets

Tickets, plans and status for the Orty project, kept as Markdown files. Git is the database.

> This repo is **public**. Never add secrets (tokens, passwords, PINs, connection strings) or customer personal data.

- One file per ticket: [`tickets/`](tickets/) (`T-0001.md`, ...)
- Screenshots: [`assets/T-<id>/`](assets/)
- Format and rules: see `Skills/trp.md` Part 3 in the Orty project
